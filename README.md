The World in One Day — 27 November 2026. An entry for make.fun's
[Sum up 27 November's world news in one image](https://make.fun/bounty/news-image-20261127)
bounty ($100 in USDC, top 50 paid).

`draw_day.py` (Python 3, Pillow) draws `entry.png` — a 1024×1024 picture of
the day: a world map with the day's flashpoints pinned, five drawn scenes,
38 verified stories across 10 region groups, a UTC timeline of the day, and a
date-check footer. `main.ts` (Node 22, standard library only) copies
`entry.png` into the output directory the grader provides.

## Run it

```sh
python3 draw_day.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
